# Taroyo

Taroyo is a personal offline AI assistant and homework management system built in Python.

I started Taroyo as a way to experiment with local AI while solving a problem I had as a college student: keeping track of assignments, deadlines, and information across multiple classes without constantly switching between different pages and systems.

## Current Version: v1.0

Taroyo currently functions as a persistent homework manager with a conversational interface.

### Features

- Add and view homework assignments
- Store assignment information in a local SQLite database
- Persistent user memory between sessions
- Persistent conversation memory
- Chill and professional interaction modes
- Local data storage
- Offline AI integration using Ollama
- Personal information and memory files excluded from the public repository

## Technologies

- Python
- SQLite
- JSON
- Ollama
- Git / GitHub
- PyCharm

## Privacy

Taroyo is designed around local storage. Personal memory, conversation history, and database contents remain on the user's machine and are excluded from this repository through `.gitignore`.

## Project Goals

Taroyo is an ongoing project. Planned improvements include:

- Assignment reminders based on due dates
- Natural-language assignment entry
- Editing existing assignments and notes
- Automatic sorting by due date
- Recovery and rescheduling after missed work
- Tracking internships, certifications, hackathons, and other opportunities
- Calendar integration
- Improved local/online AI integration

## Why I Built It

Taroyo is both a practical tool and a learning project. I wanted to build something I could actually use while developing my skills in Python, databases, local AI, software design, debugging, Git, and version control.

Rather than building individual exercises, my goal is to continue improving one system as my technical skills grow.
